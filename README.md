### 📅 [PGP17 Class Calendar Sync](https://github.com/parvnar/pgp17-class-calendar-sync)

**Problem.** Class timetables lived in a shared sheet that changed often, and students had to keep re-checking it and hunt for the right case and reading.

**Solution.** One shared Google Calendar per section, rebuilt from the batch timetable every hour. Rescheduled, extra and cancelled classes follow automatically, and each class carries its prep details: topic, book chapters, and the case and reading linked to Drive. Students add it once, with nothing to install.

`JavaScript` `Google Apps Script` `Google Sheets` `Google Calendar` `Google Drive`

### 🧱 [Dreamwall](https://github.com/parvnar/dreamwall)

**Problem.** Vision boards are usually rigid grids or cloud apps that don't feel personal or private.

**Solution.** A local-first digital dream board with an editorial, scrapbook-style wall. There is no account, server or analytics, and entries stay in the browser's own storage. It began as a product-thinking experiment.

`HTML` `CSS` `JavaScript` `IndexedDB`
